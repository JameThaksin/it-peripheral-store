## Key decisions

1. Modular monolith, npm workspaces (`apps/web`, `apps/api`, `packages/shared`).
2. TypeScript everywhere (ADR-001; reversible).
3. Server-side sessions in MongoDB + CSRF token; Argon2id passwords.
4. Money as integer satang; server computes all totals; client sends only `productId` + `quantity`.
5. Orders embed immutable item and address snapshots.
6. Checkout uses a transaction with conditional `$inc` (`stock >= qty`) → no negative stock.
7. Same-origin hosting recommended.
