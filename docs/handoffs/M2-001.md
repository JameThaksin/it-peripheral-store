# Handoff — M2-001 Full-Stack MVP

- Branch: `feature/m2-001-mvp` (from `main`). PR #1 untouched.
- Scope: catalog MVP only (no auth, cart or checkout; the checkout concurrency design is not implemented).

## Built
- `apps/api`: Express + TypeScript + Mongoose. `GET /api/health` (DB ping), `/api/categories`, `/api/products` (search, category filter, sort, pagination, strict Zod query), `/api/products/:idOrSku`. Helmet, compression, rate limit; serves the built web app on the same origin.
- Insert-only seed: 7 categories and 36 products (integer satang prices), with category counters incremented only on insert, in a transaction.
- `apps/web`: React + Bootstrap + Vite. Responsive Home, Catalog (search, category filter, sort, pagination) and Product detail pages.

## Verified (real MongoDB 8 replica set in Docker, local)
- `npm install`: OK. `npm run typecheck`: pass. `npm run build`: pass.
- `npm test`: 7/7 API smoke tests pass against real MongoDB (health, ≥30 products, repeatable seed, counters, search, filter, sort, strict validation, 404).
- Seed run twice: 36 inserted, then 0 inserted / 36 skipped.
- Playwright browser smoke on the production build: home (8 featured, 7 categories), search "keyboard" (6), all products (36), monitors filter (5), product page, no mobile horizontal scroll, 0 console errors.

## Not done / blocked
- MongoDB **Atlas**: not tested; no Atlas URI is available to this environment.
- Public deployment: no hosting account access. `render.yaml` is ready; it needs a Render (or similar) service and `MONGODB_URI` secret.
- Cart, auth, checkout, admin: next milestones.
