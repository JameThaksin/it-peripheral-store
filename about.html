The project

IT Peripheral Store is a university team project covering two parts: a responsive storefront landing page and a separate full-stack store application.

This website is a static demonstration. Shopping, accounts and checkout are not active on this page.

  • Landing page: HTML5, CSS3 and Bootstrap
  • Full-stack application: React and Bootstrap
  • Backend: Node.js, Express and TypeScript
  • Database architecture: MongoDB with Mongoose
  • Source code: GitHub repository
